# Java_Laboratory_Work
Здесь собраны мои лабораторные работы при самостоятельном изучении языка Java и ООП, а так же лабораторные работы по численным методам для университета

1. Зоопарк. Он состоит из трёх зон в которые добавляется неограниченное колличество вальеров и животных. Зоопарк заполняется с использованием CVS файлов.
2. Калькулятор. Вычисление выражения заданного строкой с использованием польской нотации
3. Численные методы. 4 лабораторные работы: интерполирование и приближение вункций, интерполирование кубическими сплайнами, решение систем линейных уравнений с разреженными матрицами специального вида, численное интегрирование(формупа средних прямоугольников). Данные для запуска можно найти в папке "значенияДляЛабораторныхЧМ"
